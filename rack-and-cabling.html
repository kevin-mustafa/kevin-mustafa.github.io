Tap a port for its details.

My records confirm what is in the rack, but not the exact shelf or unit order, so the drawing shows the switch fronts port by port and the server shelves without naming which machine is where. The router and the small 2.5 gigabit switch are not drawn in the rack because their placement is not recorded.

How the cabling is laid out

  • Two networks on two switches, joined by one fibre trunk. The core switch carries the fast 10 gigabit data traffic between servers. The access switch carries the slower things: the router uplink, remote consoles and laptops.
  • Fibre for the fast links. Every server link is multimode fibre with LC connectors and 10GBASE-SR short range modules (850 nm light), the same kind of link used between servers and top of rack switches in a data centre.
  • Bundled links. The storage server uses two fibres as one 20 gigabit link (link aggregation), and the router uses two copper cables as one link to the access switch.
  • Labels on the switch. Every core switch port has a label typed on the switch naming the machine on the far end, so the switch's own screens match the cabling.
  • Remote consoles. Each server has a network console (keyboard, video and mouse over the network, with power control where it is wired in), so I can work on a machine with no screen attached.
  • Security copy. The access switch sends a copy of all router traffic to a dedicated capture port on the security watch laptop.
