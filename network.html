How it is put together

  • One network, two speeds. All devices share one flat network (no separate virtual networks are built yet; the switches carry a single default network). Traffic is split by hardware instead: a 10 gigabit fibre switch for server to server traffic and a gigabit switch for everything else.
  • The trunk. One fibre between the two switches joins the halves. It is set up as a link aggregation group (LACP) with one member each end; an earlier second member was removed, which leaves no loop.
  • Addressing. Lab machines have fixed addresses set aside on the router; everything else is handed an address by the router, with reservations for lab devices. Each device carries one agreed name in the router's client list.
  • Out-of-band access. Each server has its own network console on the gigabit switch, so a frozen or powered-off machine can still be reached and restarted.
  • Watching the network. The security watch laptop receives a mirror copy of all router traffic for intrusion detection, plus a separate management link.
  • A known weak point. The storage server's virtual machines reach the router only through the small unmanaged switch, which has frozen before; it is recorded as a single point of failure.
