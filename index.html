What I built and fixed

Rack and cabling

Mounted the machines and switches in an open-frame rack and labelled the cables.

  • Rack mounting
  • Cable labelling

10 gigabit fibre network

Cabled three machines to an 8-port 10 gigabit managed switch over multimode fibre (SFP+ modules, LC to LC cables). Set up the switches and router with fixed address reservations.

  • Multimode fibre
  • SFP+
  • Managed switches

Tracing a storage link fault

Two drives on one machine were logging SATA link errors. I swapped their cables, tested slower link speeds, then changed a kernel setting (IOMMU passthrough, which controls how devices reach memory), after which the errors stopped.

  • Fault tracing
  • SATA
  • Linux kernel settings

Storage server upgrade

Upgraded the storage server to 128 GB of memory and verified it with a full MemTest86 pass. Mapped all twelve drives by serial number before the storage pools were built, so no drive is ever identified by a name that can change between boots.

  • Memory testing
  • TrueNAS
  • ZFS mirrored pools

Virtualisation and graphics cards

Proxmox virtual machines with graphics cards passed through, a TrueNAS storage machine, and language model training jobs running on the graphics cards.

  • Proxmox VE
  • GPU passthrough
  • Ubuntu Linux

Power and monitoring

Two UPS units for backup power, per-machine power metering through smart plugs, and Grafana dashboards for temperature, power and graphics card use. Remote consoles with power control (PiKVM, JetKVM) for working on machines without a screen attached.

  • UPS
  • Power metering
  • Grafana
  • Remote consoles
